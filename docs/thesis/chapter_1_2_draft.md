# 《基于单目视频的免标注可解释人体动作质量评估研究》第一、二章草稿

> 说明：本文稿按 Step 3.4 要求生成，引用统一保留为 `[作者，年份]` 占位。正式论文提交前，需要逐条核验作者、年份、题名、会议/期刊和数据集细节。本文中的“免标注”指免除逐帧动作缺陷标注和大规模主观质量分数标注，并不等同于完全不需要专家示范或参考模板。

## 第一章 绪论

### 1.1 研究背景

运动健康正在从经验驱动转向数据驱动。传统健身指导依赖教练现场观察，优势是判断直接、反馈具有情境感，局限也很清楚：服务时间有限、成本较高，普通用户很难在每一次训练中获得稳定的动作纠错。深蹲、弓步、硬拉等基础动作看似简单，却涉及髋、膝、踝、躯干和重心控制的协同关系。动作质量不足时，训练收益下降，关节代偿风险上升。面向大众运动健康的智能评估系统，因此不能只回答“是否完成动作”，还要说明“哪里偏差最大、偏差发生在什么时候、应该怎样修正”。

计算机视觉为低成本运动分析提供了现实基础。单目摄像头已经广泛存在于手机、笔记本和普通网络摄像头中，用户无需穿戴惯性传感器，也不需要搭建多相机动作捕捉系统。MediaPipe、RTMPose 等 2D 姿态估计方法能够在消费级设备上实时输出人体关键点；VideoPose3D、MotionBERT 等 3D 姿态估计方法进一步尝试从单目序列中恢复时空一致的三维骨架 [作者，年份]。这些进展使运动评价从封闭实验室走向家庭、校园和社区健身场景。问题也随之改变：当姿态序列可以获得时，系统如何把关节点坐标转化为可解释的动作质量判断。

动作质量评估（Action Quality Assessment, AQA）研究试图回答这一问题。早期工作多面向跳水、体操、花样滑冰等竞技项目，模型根据视频预测裁判分数或动作等级 [作者，年份]。这类任务推动了时序建模、细粒度动作识别和质量回归方法的发展，但它们通常依赖大量带分数标签的视频。对普通健身动作而言，构建同等规模的数据集并不现实。更关键的是，分数本身不足以支持纠错：用户得到 72 分，却仍不知道是膝内扣、髋屈不足，还是躯干前倾过大。本文选择以单目视频、人体姿态、时序对齐和可解释诊断为核心路线，目标是在较低标注成本下形成可落地的动作质量评估原型。

### 1.2 研究现状

AQA 领域的主流路径可以概括为三类。第一类直接从 RGB 视频学习质量分数。以 AQA-7、MTL-AQA 等工作为代表，研究者将动作视频输入卷积网络、时序网络或 Transformer，输出连续分数或排序结果 [作者，年份]。这一路线能利用图像纹理、运动轨迹和场景信息，在竞技体育数据集上表现突出。它的代价是训练数据需求高，可迁移性受项目类型影响明显，且模型判断往往难以转化为具体关节层面的建议。

第二类方法强调片段结构和动作阶段。CoRe、FineDiving、FineParser 等研究把完整动作拆解为起跳、腾空、入水等阶段，或利用细粒度动作解析提升评分稳定性 [作者，年份]。阶段建模解决了“同一动作不同时间段重要性不同”的问题。以跳水为例，入水阶段的角度和水花对最终评分影响显著；以深蹲为例，下蹲最低点和上升初段通常更能暴露髋膝踝协同问题。阶段化思路对健身动作同样有价值，但竞技体育方法往往绑定特定项目规则和标注体系，迁移到无裁判分数、无阶段标签的日常动作场景时，需要重新设计监督信号。

第三类方法从人体姿态出发，将动作质量表示为骨架、角度或动力学特征的差异。姿态特征减少了背景、服装和光照干扰，也更贴近运动学解释。许多康复评估、训练辅助和舞蹈对齐系统采用关键点轨迹、关节角度、速度曲线或时序对齐距离作为评价依据 [作者，年份]。这类方法的优势是可解释，缺点是强依赖姿态估计质量：遮挡、视角变化、快速运动和单目深度歧义都会传递到后续评分。本文沿用姿态路线，但不直接比较原始坐标，而是提取与深蹲动作相关的关节角度特征，并通过动态时间规整处理不同用户动作速度不一致的问题。

### 1.3 现有方法的局限性

现有 AQA 方法的第一个局限是标注依赖。竞技项目数据集通常包含裁判评分、动作类别或阶段标签，模型可以从大量标注样本中学习“视觉模式到分数”的映射。大众健身动作缺少这种条件。让专业教练为每段视频给出细粒度错误标签，成本高且一致性难以保证；让普通用户自标动作质量，标签噪声会直接削弱模型。本文关注的免标注并非拒绝任何先验，而是把监督需求从“大规模质量标签”降低到“少量专家示范模板”。这一设定更符合个人训练和教学场景：教练或系统只需准备标准动作样本，后续用户视频通过姿态特征和时序对齐进行比较。

第二个局限是黑盒输出。深度回归模型能预测分数，但中间机制难以解释。即使注意力图显示某些帧更重要，用户仍然需要把热区、帧号和动作错误联系起来。运动纠错需要结构化语言：哪个关节、偏差方向、偏差幅度、发生时间和纠正建议。没有这些信息，系统只能充当评分器，不能充当训练反馈工具。本文把评估结果拆成总分、阶段分、关节偏差和异常时间点，再由本地规则或大语言模型生成建议，使输出从“评价”推进到“诊断”。

第三个局限是视角敏感。单目视频天然存在深度不确定性，同一深蹲动作从正面、侧面和斜侧面拍摄时，关键点投影分布差异明显。RGB 模型可能把场景和人体外观差异误认为动作质量差异，2D 骨架模型也可能在深度方向上遗漏膝盖前移、髋后移等关键信息。3D 姿态估计能缓解这一问题，但单目 3D 结果仍受训练数据、相机参数和遮挡影响。本文在原型阶段使用 MediaPipe 的世界坐标作为伪三维输入，并在实验设计中保留视角鲁棒性分析，后续可替换为 MotionBERT 等更强的三维姿态后端。

### 1.4 本文研究内容与贡献

本文围绕“低标注成本、可解释诊断、可运行原型”展开研究。第一，构建基于单目视频的人体姿态处理流程。系统从普通视频中提取人体关键点，完成低置信度帧插值和关节命名映射，为后续特征计算提供统一输入。与直接使用 RGB 视频相比，姿态表示更接近运动学变量，也便于在失败案例中定位误差来源。

第二，设计面向深蹲动作的角度特征表达。本文不把动作质量简化为骨架坐标距离，而是围绕髋、膝、踝、肩和躯干关系提取十二个关节角特征。角度特征具有明确解释：膝关节角度反映屈伸幅度，髋膝踝链条反映下肢协同，躯干相关角度反映上身控制。该表示减少了身高、画面尺度和用户站位对评分的影响。

第三，提出基于专家模板和加权分段 DTW 的评估方法。不同用户完成同一动作的速度不同，逐帧比较会把节奏差异误判为质量差异。动态时间规整通过寻找测试序列和专家模板之间的最优对齐路径，允许动作进程在时间轴上伸缩。本文在标准 DTW 基础上加入关节权重和粗阶段划分，使稳定关节特征在距离计算中拥有更清晰的贡献，并为下蹲、最低点、上升等阶段的偏差分析留下接口。

第四，形成结构化诊断和交互式演示系统。系统输出不仅包含总分，还包含每个关节特征的平均偏差、异常比例、峰值偏差和发生时间。基于这些结构化结果，本地建议模块能够生成稳定的纠错提示；在具备 API 条件时，也可以接入大语言模型，把诊断结果改写为更自然的训练反馈。本文实现命令行脚本、Gradio 演示、FastAPI 服务和 React 前端，保证研究方法可以被运行、检查和扩展。

全文共分为五章。第一章介绍研究背景、现有方法局限和本文研究内容，说明单目视频动作质量评估的应用价值与技术挑战。第二章综述人体姿态估计、动作质量评估、时序对齐和可解释人工智能在体育分析中的相关研究，为本文方法选择提供依据。第三章描述系统方法，包括姿态提取、角度特征构建、专家模板生成、加权分段 DTW 对齐和结构化诊断规则。第四章给出实验设计与结果分析，重点比较标准 DTW 与加权分段 DTW 的差异，分析视角变化和模板数量对评估稳定性的影响。第五章总结全文贡献，讨论单目姿态误差、数据规模和动作类别扩展等限制，并提出后续研究方向。

## 第二章 相关工作

### 2.1 人体姿态估计

人体姿态估计为动作质量评估提供基础观测。2D 姿态估计的目标是在图像中定位人体关键点，例如肩、肘、髋、膝和踝。OpenPose 将关键点热图和肢体连接关系结合起来，推动了多人姿态估计的工程应用 [作者，年份]；MediaPipe Pose 进一步强调移动端实时性，适合健身、康复和交互式应用场景 [作者，年份]；RTMPose 则在速度和精度之间取得较好平衡，常被用于实时视频分析系统 [作者，年份]。这些方法输出的是图像平面坐标，优势是计算成本低，问题是无法直接表达深度方向的运动。

3D 姿态估计试图恢复人体关键点在三维空间中的位置。VideoPose3D 利用时序卷积从 2D 关键点序列提升到 3D 骨架，证明时间上下文可以缓解单帧深度歧义 [作者，年份]。MotionBERT 将姿态序列建模为时空 token，通过预训练学习人体运动结构，在单目 3D 姿态估计和动作理解任务中具有代表性 [作者，年份]。对动作质量评估而言，3D 姿态的价值不只在于坐标维度增加，而在于它能更自然地描述膝盖前移、髋关节后坐和躯干倾角等运动学现象。本文原型阶段采用 MediaPipe 提供的世界坐标作为伪三维输入，保留未来替换为 MotionBERT 或其他 3D 后端的接口。

姿态估计误差会直接影响质量评价。遮挡导致关键点漂移，宽松衣物降低肢体轮廓可见性，摄像机视角改变关节角的投影形态。运动场景还包含快速位移、身体自遮挡和画面裁切，这些因素在静态人体姿态数据集中并不总是充分覆盖。可靠的 AQA 系统必须把姿态估计看作有噪声的测量，而不是完美输入。本文通过低置信度插值、角度特征和模板容差减轻部分噪声影响，但在实验章节仍需报告失败案例，因为这些失败决定系统真实可用边界。

### 2.2 动作质量评估

动作质量评估关注动作完成质量，而非动作类别识别。AQA-7 等早期数据集将跳水、体操和滑雪等项目的视频与裁判评分对应起来，使研究者能够训练模型预测连续分数 [作者，年份]。MTL-AQA 引入多任务学习思想，在评分之外利用动作类别或难度信息帮助模型理解动作结构 [作者，年份]。这类方法把 AQA 明确建模为视觉回归问题，适合裁判规则相对稳定、评分数据可获得的竞技场景。

随着任务细化，研究者开始关注动作内部结构。CoRe 强调片段或关系建模，使模型在评分时利用动作过程中的关键阶段 [作者，年份]。FineDiving 面向跳水建立更细粒度的动作质量数据，推动模型从完整视频分数走向步骤级理解 [作者，年份]。FineParser 进一步关注细粒度动作解析，试图把复杂动作拆成可解释的组成部分 [作者，年份]。这些工作共同说明，动作质量不是单帧属性，而是由阶段、节奏和局部偏差共同决定。

健身动作与竞技评分存在显著差异。深蹲、俯卧撑、平板支撑等动作没有统一裁判分数，用户更关心安全性和训练效果。评分模型如果只输出一个连续值，无法满足纠错需求。康复和运动训练领域因此常采用姿态或传感器特征，比较患者或训练者与标准动作之间的差异 [作者，年份]。本文把 AQA 问题转化为专家模板对齐与关节偏差诊断：分数是诊断的摘要，偏差结构才是反馈的主体。

### 2.3 时序对齐方法

同一动作在不同个体之间存在天然时间差异。有人下蹲较慢，有人在最低点停顿，有人上升阶段发力更快。直接逐帧比较会把动作速度差异当成动作质量差异，尤其在视频长度不同或采样率不同的情况下更明显。动态时间规整（Dynamic Time Warping, DTW）通过非线性时间对齐解决这一问题：它在两个序列之间寻找累计距离最小的路径，使相似动作阶段可以对应起来 [作者，年份]。

DTW 的优点是可解释、无需训练、适合小样本场景。路径中的每个匹配点都可以追溯到测试动作和模板动作的具体帧，便于定位偏差发生时间。标准 DTW 也有局限。它通常假设每个特征维度贡献相同，容易让噪声较大的特征影响整体距离；它只优化全局路径，缺少对动作阶段的显式约束；当序列中存在局部异常时，对齐路径可能为了降低整体距离而掩盖关键错误。

本文采用加权分段 DTW 作为改进方向。加权机制根据专家模板中各特征的稳定性调整距离计算，稳定且有诊断价值的特征获得更高权重。分段机制把动作粗略划分为若干阶段，在每个阶段内分别对齐，降低跨阶段错配的风险。该方法不需要训练数据，适合标注稀缺场景；同时保留路径可解释性，便于后续生成“第几秒、哪个关节、偏差多大”的结构化诊断。

### 2.4 可解释 AI 在体育分析中的应用

体育分析中的可解释性具有实际意义。医疗影像或金融风控中的解释常服务于专业审查，运动训练中的解释直接服务于用户行动。一个深蹲评估系统如果告诉用户“分数较低”，用户无法据此调整动作；如果指出“最低点附近左膝轨迹偏内，平均偏差超过模板容差”，用户就能把注意力放在膝盖与脚尖方向的一致性上。体育 AI 的可解释性因此必须连接算法输出和动作语言。

现有可解释方法包括注意力可视化、显著性图、关键帧选择、骨架轨迹比较和自然语言反馈 [作者，年份]。注意力图能显示模型关注区域，但对普通训练者并不直观。关键帧选择能减少视频复盘成本，却仍需人工判断错误类型。骨架和关节角度解释更适合动作质量评估，因为它们直接对应人体结构。本文选择结构化诊断作为解释载体：总分概括整体表现，关节偏差说明错误部位，时间戳定位动作阶段，自然语言建议指导修正。

大语言模型为体育反馈提供了新的表达层。模型不必替代底层评分算法，而可以把结构化诊断翻译成用户可理解的建议。这样做有两点好处：底层评分仍由可审查的姿态特征和对齐算法决定，语言层负责组织、润色和个性化表达；当外部 API 不可用时，系统仍可回退到规则模板，保持可运行性。本文将大语言模型定位为解释生成器，而不是动作质量判定器，避免把不可控的语言模型输出作为评分依据。

从研究路线看，姿态估计、AQA、DTW 和可解释 AI 分别解决观测、评价、对齐和反馈问题。本文把四者连接成一个轻量级原型：用单目姿态获取人体运动，用角度特征降低外观干扰，用专家模板和加权分段 DTW 处理节奏差异，用结构化诊断和语言建议完成用户反馈。这一路线牺牲了端到端深度模型在大规模竞技数据上的表达能力，换取低标注成本、可审查结果和面向普通健身场景的部署可行性。
